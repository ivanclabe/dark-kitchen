QUANELA BRAND ASSETS
====================

Colors:
- Primary orange: #F97316
- Dark brown: #1C1310
- White: #FFFFFF

Files:
- quanela-logo-horizontal.png: transparent horizontal logo for web headers/navigation.
- quanela-logo-horizontal-white.png: same logo on white background.
- quanela-app-icon-*.png: app icon exports in common sizes (transparent outside the rounded-square mark).
- quanela-app-icon-master.png: highest-resolution cropped source icon.
- favicon.ico: browser favicon (16, 32, 48 px).
- site.webmanifest: basic PWA manifest.
- html-head-snippet.html: example HTML tags for web app integration.

Suggested use:
- Web header/sidebar: quanela-logo-horizontal.png
- Browser favicon: favicon.ico or 32 px PNG
- PWA/Android: 192 px and 512 px PNG
- iOS home screen: 180 px PNG (apple-touch-icon)
- Desktop app: 256 px or 512 px PNG; package-specific icon formats may still be required by Electron/Tauri.

Note:
These assets are raster PNG exports derived from the supplied image, not a vector redraw. At 16 px, the mascot details may soften; a simplified SVG redraw is recommended later for the sharpest favicon.
