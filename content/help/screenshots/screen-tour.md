Cada captura tiene **números naranjas** sobre las partes importantes; la nota con el mismo número, debajo, explica para qué sirve. Toca el título de una captura para abrir la guía completa.

> **Bueno saber:** las capturas usan un negocio de demostración con datos inventados. Tu pantalla puede verse un poco distinta según tu rol: cada quien ve solo lo que puede usar.
